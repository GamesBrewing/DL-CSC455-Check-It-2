# Check It 2
## Summary:
Windows Forms to-do list app named Check It. This is a task list where the user can add a task title, task description, and due date. Each task added will appear in a list in the lower portion of the app. Then they can edit and/or delete each task.

## Problem: 
Users need a way to visualize or track specific tasks in their life and document which tasks have already been completed. 
 
## Solution:
Allow the user to generate tabs in an app for each task. Then give them the ability to edit these tabs, delete them or change some factor to designate their importance.
 
## Requirements:
An interface for the user to interact with the app and see the tabs they create. 
 
A system that will read what the user enters and save it in memory. 
System will have to handle the user entering the following information for a task:
- Text for the name of the task.
- Text for the description of the task.
- What color they would like for the tab or ask the user to choose a priority level and system designates a color.
- Allow user to assign task Priority (low, normal, urgent) via a dropdown.
 - Favicon.
- Numbers for the due date.
- Mark task as complete.
 
System to allow the user to save the task.
System to show that task on the interface for the user.
System that allows the user to delete any task.
Confirmation system to guarantee the user wants to delete tasks.
System that saves the last task deleted as an undo button.
System to allow the user to edit the task.
